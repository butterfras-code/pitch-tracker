# B Pop Tune Hunters stage artwork

- `src/assets/b-pop-celestial-blades.svg`: original vector decoration authored for this project; abstract celestial stars, thorn-like sound-wave blades and orbital lines. The center remains quiet for pitch readings.
- `src/assets/b-pop-stage-sigil.svg`: original geometric stage-charm decoration authored for this project. It contains no writing, musical notation or functional information.

Both SVGs are project-authored code assets, use no external artwork, and are bundled into the standalone HTML. Colors in the multicolor illustration follow the B Pop Tune Hunters palette; the monochrome charm is used as a CSS mask colored by theme tokens. Existing bundled Anton lettering remains covered by `Anton.txt`.

The earlier generated cat PNG has been removed from the theme and repository. The user-supplied reference poster is not distributed with the app.
