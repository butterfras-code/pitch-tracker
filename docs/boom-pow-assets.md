# Boom Pow assets

- `src/assets/boom-pow-print.png`: original comic print generated with the built-in image-generation tool and embedded in the standalone release.
- `src/assets/bangers.ttf`: Bangers, from https://github.com/google/fonts/tree/main/ofl/bangers. SIL Open Font License retained in `docs/licenses/Bangers.txt`. Loaded locally as `Boom Pow`; no runtime network request.

## Generation prompt

Create a finished square full-bleed seamless comic-book printed paper background texture for an offline music classroom theme called Boom Pow. NOT a UI mockup. 1960s pop-art superhero comic printing: electric cyan-blue field with crisp large black Ben-Day halftone dots, energetic jagged yellow explosion bursts at several edges, a few vermilion red lightning wedges, dynamic black speed lines. Slight authentic off-white paper fibers visible in the inks, bold imperfect black brush outlines, flat screen-printed colors only cyan blue, saturated yellow, red, black and ivory. Pattern should look fantastic in narrow gutters around ivory rectangular reading panels, dense clear graphic identity. No text, no letters, no words, no speech captions, no UI controls, no gradients, no 3D rendering. Cheerful loud school music comic vibe, bold professionally inked illustration, crop-safe all-over pattern.
